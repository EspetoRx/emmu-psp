Origem dos artefatos vendorizados em vendor/ppsspp-ejs/
=======================================================

Runtime PPSSPP compilado para Emscripten/RetroArch, distribuído como core do
EmulatorJS. Não editar os arquivos desta pasta: patches, quando necessários,
devem ficar em js/adapter.js.

Fonte
-----
- Projeto: https://github.com/EmulatorJS/ppsspp
- Distribuição: release 4.3.0-pre do EmulatorJS
  https://cdn.emulatorjs.org/releases/4.3.0-pre.7z (publicada em 2026-05-17)
- URL do pacote do core:
  https://cdn.emulatorjs.org/4.3.0-pre/data/cores/ppsspp-thread-wasm.data
- Artefato interno: PPSSPP libretro em Emscripten (pthreads + WebGL2),
  build.json versão 2.0.3, minimumEJSVersion 4.3.0 (arquivos datados de
  2026-05-17). Substitui o build 2.0.2 de 2025-06-14: o core antigo renderizava
  todo o texto dos jogos e dos diálogos PSP como retângulos preenchidos, enquanto
  o PPSSPP 1.20.x oficial e este build mais novo exibem os glifos corretamente.
- Assets PPSSPP (flash0, fontes, shaders, compat.ini etc.):
  https://cdn.emulatorjs.org/4.3.0-pre/data/cores/ppsspp-assets.zip
  As PGFs e os atlas continuam byte a byte idênticos aos do PPSSPP v1.20.4;
  a diferença relevante é o binário do core (correções de fonte/PPGe de 2026).
- Licença do runtime: GPL-2.0-or-later, com avisos adicionais do PSPSDK.
  Texto incluído em vendor/ppsspp-ejs/license.txt (inalterado em relação ao
  build anterior).

Obrigações de licença
---------------------
O Emmu já distribui cores GPL. Este módulo é licenciado como GPL-3.0-or-later
(LICENSE na raiz do crate), compatível com o GPL-2.0-or-later do PPSSPP. O texto
de licença do core e os avisos do PSPSDK precisam continuar no bundle desktop e
web. Se os binários forem atualizados, atualize também este arquivo e o
THIRD-PARTY-NOTICES.txt do desktop.
